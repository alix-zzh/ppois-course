# Дополнительные задания

Список тем для дополнительной лабораторной работы (назначается, например,
при существенном нарушении академической честности — см.
`common_requirements.md` — или по решению преподавателя).

## Структуры данных

1. Bloom Filter.
2. Список с пропусками ([Skip list](https://en.wikipedia.org/wiki/Skip_list)).
3. Красно-чёрное дерево.
4. Суффиксное дерево.
5. Фибоначчиева куча.
6. Система непересекающихся множеств (Disjoint Set Union).
7. Дерево Меркла.
8. Array (динамический массив).
9. Linked List (связный список).
10. Stack (стек).
11. Queue (очередь).
12. Hash Table (хеш-таблица).
13. Binary Tree (бинарное дерево).
14. Graph (граф).
15. Heap (куча).

## Алгоритмы

1. Бинарный поиск.
2. Сортировка слиянием.
3. Быстрая сортировка.
4. Поиск в глубину (DFS).
5. Поиск в ширину (BFS).
6. Алгоритм Дейкстры.
7. Задача о рюкзаке вместимостью `X` для предметов объёмом `x1, x2, …, xn`.
8. Алгоритм A*.
