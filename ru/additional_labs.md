# Дополнительные задания

Список тем для дополнительной лабораторной работы (назначается, например,
при существенном нарушении академической честности — см.
`common_requirements.md` — при нарушении правил поведения на занятиях или
при четвёртом и последующих пропусках без уважительной причины — см.
`conduct_rules.md` — либо по решению преподавателя).

## Требования к сдаче

Помимо программной реализации, по своему варианту задания необходимо
**от руки, на бумаге**, подробно расписать принцип работы алгоритма или
структуры данных:

- пошаговое описание работы (в том числе на конкретном числовом примере —
  трассировка выполнения с промежуточными состояниями структуры/переменных);
- временную и пространственную сложность (Big O) с кратким обоснованием;
- для структур данных — инварианты, которые она поддерживает, и то, как они
  сохраняются при операциях изменения.

Рукописный разбор сдаётся вместе с защитой лабораторной работы и является
обязательной частью сдачи наравне с кодом и тестами.

## Структуры данных

1. Bloom Filter.
2. Список с пропусками ([Skip list](https://en.wikipedia.org/wiki/Skip_list)).
3. Красно-чёрное дерево.
4. Суффиксное дерево.
5. Фибоначчиева куча.
6. Система непересекающихся множеств (Disjoint Set Union).
7. Дерево Меркла.
8. Array (динамический массив).
9. Linked List (связный список).
10. Stack (стек).
11. Queue (очередь).
12. Hash Table (хеш-таблица).
13. Binary Tree (бинарное дерево).
14. Graph (граф).
15. Heap (куча).
16. АВЛ-дерево (AVL tree).
17. B-дерево (B-tree).
18. Префиксное дерево (Trie).
19. Дерево отрезков (Segment Tree) с поддержкой отложенных обновлений
    (lazy propagation).
20. Дерево Фенвика / дерево бинарных индексов (Fenwick tree, BIT).
21. Декартово дерево (Treap).
22. Splay-дерево (Splay tree).
23. LRU-кэш (Least Recently Used Cache).
24. Разреженная таблица (Sparse Table) для запросов минимума/максимума на
    отрезке (RMQ).
25. Count-Min Sketch.

## Алгоритмы

1. Бинарный поиск.
2. Сортировка слиянием.
3. Быстрая сортировка.
4. Поиск в глубину (DFS).
5. Поиск в ширину (BFS).
6. Алгоритм Дейкстры.
7. Задача о рюкзаке вместимостью `X` для предметов объёмом `x1, x2, …, xn`.
8. Алгоритм A*.
9. Алгоритм Беллмана — Форда (кратчайшие пути с отрицательными весами рёбер).
10. Алгоритм Флойда — Уоршелла (кратчайшие пути между всеми парами вершин).
11. Алгоритм Прима (минимальное остовное дерево).
12. Алгоритм Крускала (минимальное остовное дерево).
13. Топологическая сортировка графа (алгоритм Кана либо на основе DFS).
14. Поиск компонент сильной связности графа (алгоритм Тарьяна либо
    Косарайю).
15. Поиск мостов и точек сочленения в графе.
16. Алгоритм Кнута — Морриса — Пратта (KMP) для поиска подстроки.
17. Поиск наибольшей общей подпоследовательности (LCS) и наибольшей
    возрастающей подпоследовательности (LIS).
18. Алгоритм Форда — Фалкерсона (поиск максимального потока в сети).
19. Расстояние Левенштейна (редакционное расстояние между строками).
20. Алгоритм Хаффмана (сжатие данных с использованием префиксных кодов).
