# PPOIS — Design of Intelligent Systems Software

Course materials for the "Design of Intelligent Systems Software" course
("Проектирование программного обеспечения интеллектуальных систем"): lab
assignments, grading criteria, theory defense questions with self-check
answers, and reference materials. The course focuses on OOP and building
high-quality software.

Available in two languages, kept in sync — pick one:

- 🇷🇺 [`ru/`](ru/) — original Russian version
- 🇬🇧 [`en/`](en/) — English translation

## Structure

Each language directory contains the same set of files:

| File | Contents |
|---|---|
| `common_requirements.md` | Requirements common to every lab: allowed languages, LLM/GenAI usage, testing, the CLI interface, the repository, academic integrity, defense (including the code-accountability rule), the final theory mini-lecture, CI/CD, and common mistakes |
| `lab1.md` | Lab #1 — OOP fundamentals: designing a class (multiple variants) |
| `lab2.md` | Lab #2 — a large-scale OOP project (individually assigned domain) |
| `lab3.md` | Lab #3 — a large-scale OOP project on a second, different domain |
| `lab4.md` | Lab #4 — generic programming: sorting and containers/graphs |
| `additional_labs.md` | Topics for the extra lab assignment (data structures and algorithms), plus the handwritten-explanation requirement |
| `questions.md` | The list of theory defense questions |
| `questions_help.md` | Self-check answers to the questions in `questions.md` |
| `grade.md` | Grading criteria and the ten-point scale |
| `checklist.md` | Instructor checklist for reviewing a submitted lab assignment |
| `safety_precautions.md` | Computer lab safety rules |
| `conduct_rules.md` | Classroom conduct rules: prohibited behavior, and what's allowed |
| `useful_links.md` | Supplementary videos, books, and sites |

## Notes

- Lab assignments 1 and 4 were originally written for C++ only; both files
  now include a correspondence table mapping the C++-specific requirements
  (operator overloading, templates, header/implementation separation) to
  Java, C#, and Python.
- Labs 2 and 3 share the same project template; each is completed against a
  different, individually assigned subject domain.
- When updating one language version, mirror the change in the other so the
  two stay in sync.
