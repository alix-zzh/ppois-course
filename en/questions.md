# Theory Defense Questions

The list of questions for the oral (5 questions) and written (10 questions)
theory defense — see `common_requirements.md`. Self-check answers — see
`questions_help.md`.

## Paradigm and OOP Fundamentals

1. What is OOP?
2. Describe the difference between a class and an object.
3. Explain the difference between instance methods/fields and class
   methods/fields.
4. The "is-a" relationship and the "has-a" relationship in OOP.
5. Core OOP principle: encapsulation.
6. Core OOP principle: inheritance.
7. Core OOP principle: abstraction.
8. Core OOP principle: polymorphism. Parametric polymorphism (generics).
   Ad-hoc polymorphism.
9. What is multiple inheritance.
10. The "diamond problem" in multiple inheritance and approaches to
    resolving it.
11. Association, aggregation, and composition.
12. Constructors in OOP.
13. The `this` pointer/reference.
14. Access modifiers in OOP.
15. Getters and setters.
16. Describe the concept of an "interface" in the context of OOP.
17. Mutable and immutable objects.
18. Covariance, contravariance, invariance.
