# Additional Assignments

A list of topics for the extra lab assignment (assigned, for example, in
case of a serious academic-integrity violation — see
`common_requirements.md` — a classroom-conduct violation, or a fourth or
later unexcused absence — see `conduct_rules.md` — or at the instructor's
discretion).

## Submission Requirements

In addition to the code implementation, for your assigned variant you must
**write out by hand, on paper**, a detailed explanation of how the
algorithm or data structure works:

- a step-by-step description of how it works (including a concrete
  numeric example — a trace of execution with the intermediate states of
  the structure/variables);
- the time and space complexity (Big O) with a brief justification;
- for data structures — the invariants it maintains and how they are
  preserved across mutating operations.

The handwritten write-up is submitted together with the lab defense and is
a mandatory part of the submission, on par with the code and tests.

## Algorithms

1. Binary search.
2. Merge sort.
3. Quicksort.
4. Depth-first search (DFS).
5. Breadth-first search (BFS).
6. Dijkstra's algorithm.
7. The knapsack problem with capacity `X` for items of sizes
   `x1, x2, …, xn`.
8. A* algorithm.
9. Bellman–Ford algorithm (shortest paths with negative edge weights).
10. Floyd–Warshall algorithm (shortest paths between all pairs of
    vertices).
11. Prim's algorithm (minimum spanning tree).
12. Kruskal's algorithm (minimum spanning tree).
13. Topological sorting of a graph (Kahn's algorithm or DFS-based).
14. Finding a graph's strongly connected components (Tarjan's algorithm or
    Kosaraju's algorithm).
15. Finding bridges and articulation points in a graph.

    increasing subsequence (LIS).
18. Ford–Fulkerson algorithm (finding the maximum flow in a network).
19. Levenshtein distance (edit distance between strings).
20. Huffman coding (data compression using prefix codes).
